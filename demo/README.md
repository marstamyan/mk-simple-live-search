# Обучающее видео

Версия без звука: `artifacts/mk-simple-live-search-english-silent.mp4`. Скрипт `node demo/lesson-silent.cjs` сохраняет все действия и английские инструкции, удаляет аудиодорожку и сокращает удержания кадров, добавленные под озвучку. Вариант с голосом сохранён отдельно.

Последний вариант: `artifacts/mk-simple-live-search-english-guide.mp4` — 2:07, девять отдельных шагов с английской озвучкой. Действие, шорткод и ожидаемый результат показаны рядом. Сценарий: `lesson.json`; запись: `lesson-capture.cjs`; английский голос: `lesson-voice.ps1`; макет: `src/lesson.tsx`; сборка: `lesson-render.cjs`. Используется установленный голос Microsoft Zira Desktop. Предыдущие короткие варианты сохранены отдельно.

Текущая версия ролика — на английском, около 38 секунд. Для её повторной записи используйте `setup-demo-en.php` вместо `setup-demo.php`. Страницы, результаты и подписи записаны на английском. В `capture.cjs` сокращены ожидания, заставка и финал занимают по одной секунде. Новый файл: `../artifacts/mk-simple-live-search-tutorial-en-1080p.mp4`. Исходный русский MP4 сохранён отдельно.

Видео показывает настоящие действия в изолированном WordPress: путь установки ZIP, активированный плагин, ввод шорткода в Gutenberg, живые результаты, режимы поиска, лимит, публичный тип `portfolio`, несколько полей и клавиатуру. Интерфейс и выдача не нарисованы: `capture.cjs` записывает кадры Chromium через CDP, Remotion создаёт русские титры, а FFmpeg накладывает запись и собирает видео. Озвучки нет.

## Повторить демонстрацию

Используйте отдельный локальный WordPress, который можно удалить. Не запускайте подготовку на рабочем сайте: она создаёт и обновляет записи с демонстрационными адресами `coffee-guide`, `coffee-recipes`, `coffee-tools`, `home-guide`, `coffee-private`, `coffee-draft`, `coffee-password`, `coffee-brand`, `bakery-brand`, `live-search`, `search-modes`, `search-options`, `search-tutorial`. Учётные записи и список активных плагинов скрипт не изменяет.

1. Установите и активируйте собранный ZIP плагина на локальном WordPress.
2. Скопируйте `portfolio-type.php` в `wp-content/mu-plugins/`. Это только регистрация демонстрационного типа; сам плагин такой тип не создаёт.
3. Выполните `wp eval-file /path/to/demo/setup-demo.php --user=YOUR_ADMIN` из каталога тестового WordPress. Для повторения браузерных проверок задайте **Настройки → Постоянные ссылки → Простые**: одна из проверок специально проверяет REST-адрес с `rest_route`.
4. В этой папке выполните `npm install`. Для записи нужен Playwright, Chromium/Edge и FFmpeg. При необходимости установите `npm install --no-save playwright` и браузер.
5. Передайте переменные окружения `WP_DEMO_URL`, `WP_DEMO_USER`, `WP_DEMO_PASSWORD`, `PLAYWRIGHT_MODULE` (путь к модулю или `playwright`), `BROWSER` (путь к браузеру), `FFMPEG` (путь к FFmpeg). Пароли в проект не записывайте.
6. Выполните `npm run capture`. Записи появятся в `public/`, монтажные данные — в `chapters.json`.
7. Выполните `npm run render` (быстрый монтаж Remotion + FFmpeg). Итог: `../artifacts/mk-simple-live-search-tutorial-ru-1080p.mp4`. Для контрольных кадров: `node render.cjs --stills`.

В исходной записи использовались WordPress 7.1.4, PHP 8.4.27, SQLite, тема Twenty Twenty-Five, Edge и Remotion 4.0.543. Для читаемости записи скрипт немного уплотняет отступы темы. Код и стили плагина при записи не подменяются. В SQLite кириллический `LIKE` зависит от регистра, поэтому демонстрационные заголовки и запрос начинаются со строчного `кофе`.

На текущем компьютере `capture.cjs` и `render.cjs` умеют использовать уже установленные библиотеки из соседнего проекта `simple-alert-box`; эти пути служат локальным запасным вариантом. На другом компьютере установите зависимости в `demo/node_modules` и задайте пути окружением. Сырые кадры, записи браузера, сборка и готовое видео не входят в ZIP плагина.
